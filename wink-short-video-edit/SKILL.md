# Wink 短视频剪辑流程

在 Windows Wink 桌面端按用户给定的流程处理视频。用户明确说“开始”或要求执行某一步后才操作；执行单一步骤时，完成该步并停下。用户要求跑完整流程时，按以下顺序完成，不在每个可逆的界面步骤之间重复询问。只使用本文件列出的设置；不要把旧流程里的速度、降噪、人声增强或中间停顿剪辑要求自行加回来。

## 输入与准备

- 确认本次原视频文件路径，并在 Wink 中新建人像美容项目、导入该文件。
- 按用户当前指令确定执行范围。若输入文件、指定配方或音乐名称不明确，才询问对应缺项。
- 用当前屏幕状态定位控件；每次重要操作后重新读取界面，避免依赖旧坐标或过期控件索引。

## 处理步骤

1. **裁剪首尾无声部分。** 分析原视频音轨的人声活动，找出第一处和最后一处人声。只移除开头、结尾没有人声的部分，中间停顿保留。边界不确定时保留少量余量，避免切掉辅音或句子开头结尾。优先在 Wink 时间线上定位边界、切分并删除多余片段；检查总时长和首尾画面。
2. **生成中英双语字幕。** 进入“视频剪辑 → 文字 → 智能字幕”，识别范围选时间线上所有视频片段，识别语言选简体中文，双语字幕选英语，开始识别并等待完成。
3. **设置识别字幕颜色。** 选中上方的中文字幕，在右侧“样式”面板确认“效果调整将对所有识别字幕生效”已勾选；打开颜色选择器，选择“预设颜色”第一行第五个色块（已观察到的颜色值为 `FCCA00`）。切换到另一条中文字幕确认颜色同步生效。此步骤设置颜色，不添加独立文字层，也不把收藏文字模板误当成字幕样式。
4. **应用美容配方。** 选中视频，在“人像美容 → 美容配方 → 我的 → 手机端”中选择配方“1”。确认卡片显示已选中。Wink 可能提示该人像美容效果应用到主体的所有片段；这符合当前操作方式。
5. **添加背景音乐。** 进入“视频剪辑 → 音频 → 收藏”，选择用户指定曲目；本流程默认曲目为“LOW”，除非用户在本次任务指定其他名称。若曲目显示下载按钮，先下载；下载后点击加号添加到时间线。将音轨起点与视频起点对齐。把播放头放在视频结束点，选中音轨并切分，选中视频末尾以后的音频片段并删除。选中保留的音频片段，把右侧音量输入框设为 `4`；提交输入后重新选中音轨，确认字段仍显示 `4`，并检查音轨结束边界与视频结束边界对齐。
6. **导出。** 仅在用户要求本次导出或要求跑到导出的完整流程时执行。沿用 Wink 导出窗口当前默认参数，不自行更改格式、分辨率、帧率或码率。保存目录设为原视频所在文件夹；保留导出对话框给出的默认文件名，并记下文件名和完整路径。若同名输出已存在，不覆盖；改用不冲突的新文件名。等待 Wink 显示完成，并核实输出文件存在、大小非零且时长可读取。点击导出或出现加载动画都不等于导出成功。

## 停止条件与回报

- 只执行用户本次要求的步骤；用户要求某一步完成后停止时，不继续后续步骤。
- 若界面布局变化、目标曲目/配方无法唯一确定、操作结果不明、导出失败或发现文件名冲突无法安全解决，停在当前安全状态并如实报告，不盲目重复点击。
- 完成后简要报告已完成的步骤；导出时报告文件名、保存路径和验证结果。不要声称未验证的结果已经完成。
- 本流程不包含平台登录、上传、定时或公开发布。用户之后另行要求上传时，再检查可用的平台连接或工具；公开发布仍需本次明确指令。
