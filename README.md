# Wink 短视频自动剪辑 Skill

## 项目简介

这是一个面向 Wink Windows 桌面端的个人自动化 Skill。目标是把重复的视频剪辑流程整理成清楚、可复用的操作指引，并通过屏幕状态检查逐步控制 Wink。

本项目目前是 **UI 自动化原型**：Skill 以 Markdown 流程说明为主，桌面操作由 `@oai/sky` 执行。本次实践验证了部分剪辑步骤，也暴露了界面自动化和 Wink 会员功能带来的限制；它还不是无需检查即可稳定完成全部导出的成品工具。

## 设计目标

- 从用户给定的视频文件导入 Wink 人像美容项目。
- 只去除开头和结尾的无声段，保留中间停顿。
- 生成简体中文识别、英语副字幕的双语字幕。
- 将识别字幕设置为指定颜色 `#FCCA00`。
- 应用用户指定的美容配方，并添加收藏音乐 `LOW`，音量设为 4。
- 用户要求时使用 Wink 当前默认导出参数，并核对文件是否真正生成。
- 将平台上传和公开发布排除在本 Skill 范围外。

## 操作流程

1. 确认源视频路径，并在 Wink 新建项目、导入视频。
2. 根据人声活动定位首句和末句，保留少量边界余量后剪掉首尾静音；不处理视频中间的停顿。
3. 使用智能字幕，选择时间轴上的所有视频片段、简体中文识别和英语双语字幕。
4. 选择上方中文字幕，在“效果调整将对所有识别字幕生效”开启时，将预设第一行第五个颜色应用到字幕；再抽查另一条中文字幕。
5. 在“人像美容 → 美容配方 → 我的 → 手机端”选择配方“1”。
6. 在“视频剪辑 → 音频 → 收藏”添加 `LOW`，将音频起点对齐视频起点，修剪多余尾音，设音量为 4 并重新检查数值。
7. 用户要求导出时保留 Wink 导出窗口默认参数，保存到源视频所在目录；等待完成并检查文件存在、大小非零和时长。

## 本次实践记录

使用 Wink 3.11.5 和示例视频完成了以下验证：

- 视频成功导入新建项目。
- 生成了简体中文和英语双语字幕。
- 中文字幕的全局样式颜色设置为 `#FCCA00`，并在另一条中文字幕上进行了检查。
- 应用了“我的 → 手机端 → 1”美容配方。
- 从收藏添加了 `LOW`，将音轨移至视频开头；音量控件的实际值核实为 4。
- 移除了开头无声片段，剪后开头可以正常显示人物。

### 未完成项与原因

- **结尾静音未能可靠裁掉。** 尾段分割后预览出现黑屏风险，因此撤销了尾段删除，避免把可能有问题的结果当作成片。
- **音乐尾部未与最终视频时长重新精确对齐。** 音乐曾按原时间线裁短；随后调整视频片段后，没有完成再次核对和修剪。
- **没有生成导出文件。** 默认导出设置显示 2K、MP4、30 FPS、推荐码率、H.264 和 AAC 192 kbps。点击导出后 Wink 打开了 SVIP 付费页面；未进行购买，也没有确认输出文件。

因此，本次结果应描述为一次 **部分成功的端到端 UI 自动化测试**，不能声称已完成完整剪辑和导出。

## 设计经验

- 将用户口述的流程拆成有顺序的步骤，并为每步写清入口、目标设置和完成条件。
- 重要操作后重新读取当前界面，确认结果再继续，减少依赖旧坐标或过期状态。
- 明确自动化边界：界面动作可以执行，但预览异常、会员限制和文件导出都必须根据实际结果判断。
- 用“完成、未完成、原因”记录运行情况，避免把点击按钮等同于操作成功。
- 把发布平台登录、上传和公开发布留在独立流程中，不让剪辑 Skill 越界代发。

## 使用方式

在 Codex 中调用：

```text
$wink-short-video-edit
视频路径：<本地视频完整路径>
请按 Skill 流程剪辑；如果某一步无法完成，请继续独立的后续步骤，并在最后列出完成项和问题。
```

Skill 指令文件位于 [`wink-short-video-edit/SKILL.md`](wink-short-video-edit/SKILL.md)。实际可用性取决于当前 Wink 版本、窗口状态、素材和账户权限。
